## Info
FastApi blogpost project. <br>
Servers both api and frontend.

## Tech Stack

### Backend
- Python
- FastAPI
- SQLAlchemy
- Alembic
- PostgreSQL (production)
- SQLite (local/dev)
- JWT authentication
- Pydantic / Pydantic Settings
- SMTP email support for password reset

### Frontend
- Jinja2 templates
- Bootstrap 5
- Vanilla JavaScript
- Static assets served by FastAPI
